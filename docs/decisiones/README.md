# Decisiones de arquitectura (ADR)

[Volver al inicio](../00-inicio.md)

Un archivo por decisión: `ADR-NNN-<tema>.md` (por ejemplo `ADR-001-base-de-datos.md`), numerado en orden. Se copia de [plantilla-adr.md](plantilla-adr.md).

Una decisión reemplazada no se borra: se marca como **Reemplazada por ADR-NNN**. Sin datos sensibles; lo privado va en `../privado/`.
