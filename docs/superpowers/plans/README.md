# Planes de implementación

[Volver al inicio](../../00-inicio.md)

Planes creados con `superpowers:writing-plans` a partir de un diseño aprobado. Nombre: `YYYY-MM-DD-<tema>.md`.

Cada plan enlaza su diseño, indica su estado (Propuesto o Aprobado, con fecha) y marca qué tareas pueden encargarse **en paralelo** porque no comparten archivos ni dependencias. Un plan Propuesto no autoriza implementar.
