# Diseños (specs)

[Volver al inicio](../../00-inicio.md)

Diseños creados con `superpowers:brainstorming`. Nombre: `YYYY-MM-DD-<tema>-design.md`, con la fecha real de creación.

Cada diseño indica su estado (Propuesto o Aprobado, con fecha). Un diseño Propuesto no autoriza escribir el plan ni implementar. Si incluye frontend, contiene la dirección visual, los tokens y los componentes definidos con ui-ux-pro-max.
